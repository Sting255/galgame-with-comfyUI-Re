## 2. 接入范围与兼容修正

- **游戏模块**：游戏中心、沙箱 iframe、官方跑团、社区 GitHub／ZIP 包、存档、游戏媒体与开发重载。按 `AGENTS.md` 的游戏模块例外使用独立游戏 UI；主站继续保留 Linshe 规范。本地已移除的小镇未恢复，游戏桥接移除 `get_town_state`，角色目录与场景姓名匹配过滤系统角色。
- **图片与服装**：保留 `characterPersona`、单图穿着快照、目标日期、重拍来源和多角色所有权规则；游戏输出对接既有生图链路，保留队列、锁和本地参数语义。
- **立绘迁移**：保留 `world_sig`／世界观过期检测、身份锚点、角色与玩家独立任务；旧父表复制、互动区域外键重建、旧表删除按顺序完成，任务重开和恢复保留原参数。
- **LLM**：合并模型能力与输入上限；保留本地网关兼容、脱敏、续写、取消及并发控制。请求预算作用于每次实际请求，包括 provider 400 回退、thinking 回退、恢复和续写；小预算不能被恢复分支静默扩大。
- **访问控制**：设备门禁覆盖所有主页面。游戏脚本不获得宿主 Cookie／Bearer；只读游戏资源可在 opaque-origin iframe 加载。游戏媒体使用 24 小时路径签名；仅签本游戏媒体，声明 `bridge:read` 才可签宿主图库／头像。拒绝路径越级、跨游戏、过期、篡改、API 和写操作，签名响应禁止缓存。
- **备份**：数据库之外纳入 `data/game` 和 `data/games_community`，导入使用相同白名单；默认导出清除游戏 GitHub 设置中的凭据，只有显式包含凭据才保留。仍采用原有资产合并语义。
- **GitHub 与发布**：共享代理／下载工具，启动器代理只作用于当次 Git 命令，保留本地初始化、tag 和 TLS 重试。继续仅交付 Windows 桌面包，保留脏树、精确 tag、敏感历史、秘密文件与原生依赖门禁。
- **生成产物**：`agent-core/public` 继续是忽略的生成目录，不纳入源码提交；本轮生产构建同步到该目录。一次性检查脚本、截图、日志、临时库和构建缓存完成后清理。
