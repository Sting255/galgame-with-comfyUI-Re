# 10｜生图描述容量与保真复核

> 日期：2026-11-19—20；承接 [09](09-并行收口与候选包验收.md)。
>
> 用户纠正：核实约束是否真正生效、实际多少文本可用，不再把 800 字符当作验收指标。
>
> 结论：800 不是本机 Anima 链路的硬容量。943 字符真实描述完整通过分词与原编码器／适配器；2894 字符合成探针的 622 个 T5 token 也完整通过适配器，没有在 512 处截断。后者仅证明这一次编码可执行，不证明同长度任意文本都能准确成图，更不是新的统一上限。

## 1. 先区分要验证的行为

1. **文本保真**：身份标签、每个人的外观、服装归属、动作、日期和时刻是否还在最终描述里。不能因字数较短就视为通过。
2. **链路保真**：解析、存储、人数标签处理及工作流拼装是否截断或改写这些事实。
3. **编码容量**：当前安装版本、实际模型权重及 tokenizer 能否完整处理输入，而非套用别的 CLIP 或模型默认阈值。
4. **图像遵从**：图像里的人数、服装、动作、目光与位置是否符合要求；编码成功不能替代逐项目检。

字符数只是测量值。英文中的字数、字符数、Qwen token 数与 T5 token 数不能直接互换；同样长度的文本也不保证 token 数相同。

## 2. 本机原实现与真实编码

验证对象是原整合包的实际安装源码与权重，不依据远端 master 推定本机行为。ComfyUI 根目录为整合包中的 `ComfyUI-aki-v3/ComfyUI`。

| 本机源码 | 核实到的行为 |
|---|---|
| `comfy/text_encoders/anima.py:8–28,48–51` | Qwen／T5 wrapper 的 `max_length=99999999`、`pad_to_max_length=false`；T5 ids 保留完整首块。该配置值不等于可用容量承诺 |
| `comfy/sd1_clip.py:260–284,572–674` | 按 wrapper 长度分块，实际路径未指定 `truncation=True`，完整 embeddings 进入 transformer，没有 800 字符裁切 |

| `comfy/model_base.py:1533–1548`、`comfy/ldm/cosmos/predict2.py:872,920–925` | 原 T5 ids／weights 进入 preprocess，context 原样传入各 block；未发现按 512 裁剪 |

943 原文 SHA256 为 `28f9d4c60a8fedb38a6cae7cff320c77004c6168da59ea43a6be54167d2af8be`。旧 1050 字符样例未保留原文，不补造 token 统计。

| 样本 | Qwen encoder 输出 | adapter 原输出 | preprocess 最终 condition | 有限值 | 编码／适配用时 |

| 943 字符 | `[1,230,1024]` | `[1,244,1024]` | `[1,512,1024]`，仅向上补零 | 全部有限 | 1.169／0.258 秒 |

隔离说明：没有启动 Comfy 监听、LLM 请求或扩散采样；没有改模型文件或原模型算子。烟测进程仅将 `tempfile.tempdir` 指向已存在目录，并让可选 INT8 能力的无参探测显式使用 CPU；所有模型参数和输入均确认 CPU。运行库在 forward 后报告 CUDA 已初始化，不能表述为“CUDA 从未初始化”。成功文件写入、网络与子进程均为 0；一次 `socket.bind` 探测被审计阻断，没有成功监听。早期工具兼容尝试在 forward 前退出，不计为模型执行成功。

专用输入校验、HTTP 体积限制、照相馆有效英文检查等并未统统删除。立绘等专用任务中的旧长度措辞也没有顺带全局替换；本次证据不外推为所有模型和所有任务的通用容量。
