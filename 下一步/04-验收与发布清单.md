# 04｜验收与发布清单

> 这是交付门槛，不是建议列表。每项记录：执行人、日期、commit、环境、结果、证据路径。  
> 状态只能写：未执行 / 通过 / 失败 / 按条件跳过 / 不适用。没有“基本通过”。

## 1. 验收环境与数据隔离

### 固定环境

- [ ] 源码为精确 commit，工作树 clean；记录 `git rev-parse HEAD` 与 `git status --short`。
- [ ] Node 使用仓库 runtime 22.18.0，确认 ABI 与 better-sqlite3 匹配。
- [ ] 后端端口从 `.env`/统一解析器读取，不在脚本里另猜 3099。
- [ ] 向量服务仅回环 8765；ComfyUI 地址以项目当前配置为准；Vite 开发端口 5173。
- [ ] 后端测试和冒烟一律 `DB_PATH=:memory:`，禁止写入 `agent-core/data/agent.db`。
- [ ] 不读取、不打印、不提交真实 `.env`；测试使用专门的测试 provider 配置。
- [ ] 真实数据迁移只在用户授权的副本上进行；临时截图、日志、脚本用完清理。

### 不能混用的结论

- “进程启动”不等于“业务链路正常”。
- “DOM 正常”不等于“视觉正常”。
- “lint/build 通过”不等于“测试通过”。
- “测试通过”不等于“测试覆盖该功能”。
- “ComfyUI 不在线”不等于“生图冒烟通过”。
- “延期已保留”不等于“延期会自动续跑”。

```bash
node scripts/发布-校验并打包.mjs --gates-only

./runtime/nodejs/node.exe --require ./agent-core/test/force-memory-db.cjs --test "agent-core/test/*.test.js"

```

记录：

- [ ] 静态导入、项目健康、前端构建全部通过。
- [ ] 后端测试数量与当前基线一致或增加，失败为 0；基线为 63。
- [ ] TTS 测试失败为 0；基线 56 项、47 通过、9 条件跳过。跳过原因逐项合理。
- [ ] 新增消息/任务/备份回归进入 CI；不是临时脚本。
- [ ] lint 无 error；warning 有下降限额，不能永远接受 687 条。
- [ ] 生产依赖无未接受的高危公开告警；例外记录可达性、理由、到期日。
- [ ] 前端构建后只提交约定产物，不把本地 data/配置带入变更。

## 3. 核心功能验收矩阵

> 每个涉及改动的功能都必须走“正常 + 边界 + 中断恢复”。没有改动的模块至少在候选版本做一轮冒烟。

| 功能 | 正常路径 | 必测边界 | 通过标准 |
|---|---|---|---|
| 私聊 | 发文、流式回复、历史、图片更新 | 截断续写、切角色、断流、刷新 | 不串角色、不重复、不永久等待；已落库可恢复 |
| 群聊 | 发言、聚合、多角色、图片、冷场 | 首帧不来、读中停帧、切群、离页、连续发送 | sending 有终态；失败可重试；A 群不堵 B 群；不重复轮次 |
| 全局 SSE | 主动消息、延迟回复、日程变化 | 立绘页往返 3 次、重连、重启 | handler 不增长；ID 幂等；提示音/Toast 不重复 |
| 角色 | 新建、导入、编辑、删除、系统角色 | 本体编辑、manual 锚点、复杂关联删除 | 作用域正确；身份不漂；删除事务完整 |
| 外观/服装 | 三套内置、自定义、限时、换装 | work 保护、身体修改、形态恢复 | 身体真源一致；衣服不改身体；临时效果可恢复 |
| 生图 | 聊天/立绘/朋友圈/媒体/照相馆 | ComfyUI 停、慢响应、超大图、队列满、取消 | 有界队列、终态可见、不重复提交、不带错误身份 |
| LLM JSON | 完整、围栏、截断续写、整份重写 | 拒答、修复缺字段、连续无进展 | 半截不公开；合法围栏不误续写；失败有明确终态 |
| 日程/睡眠 | 生成日程、睡眠/唤醒、程序时间 | 生成中睡着、临时唤醒、跨天 | 统一 isSleeping；不错乱真实/程序时间 |
| 朋友圈 | 发帖、评论、点赞、筛选、补发 | 2000+ 帖、睡眠互动、延迟评论重启 | 首屏分页；逐说话人合法；不丢不重评论 |
| 媒体 | 新批、补图、发布、丢弃、重生 | 生成中删除角色、睡眠延期、feed discarded | 不复活、不烧废图；醒后只发布不重复生图 |
| 奇遇 | 自动首幕、选择、推进、结束 | 生成期间睡眠/关开关/删除 | 自动公开前复查；手动语义不被误伤 |
| 日记 | 草稿、确认、三图、历史 | 延期、重启、手动重试、快照回滚 | deferred 自动续；不覆盖确认稿；不重复公开 |
| 信箱 | 收信、生成、三图、回信、失败 | 睡眠、重试上限、启动回收 | 现有生成前后闸门保持；状态与素材一致 |
| 宿舍 | 房间、入住、共同日程 | 系统角色、睡眠、跨天 | 不引入系统角色；日程真源一致 |
| 神说 | 会话、工具调用、权限提交 | 截断、工具失败、并发提交 | 工具状态真实；不越过公开/提交闸门 |
| 记忆 | 文本/向量召回、整理、provider 切换 | 服务离线、错维度、恢复后代际 | 不可用可观察；重建不白烧；不错误标记 indexed |
| TTS | API/本地、音色、播放、GPU 互斥 | adapter 退出、服务重启、无模型 | 非空服务 Token；进程可回收；无显存争抢 |
| 备份 | 导出、脱敏、含秘密、导入 | 少图到多图、强杀、错 hash、旧版本 | 语义一致；失败回滚；无秘密误泄漏 |
| 设置 | LLM/图像/功能/主题/设备 | 无密钥、慢网、非法 URL、重试 | 错误可读；秘密不回显；配置来源一致 |

## 4. 异步故障注入清单

这些不是“看一眼代码”能代替的验收。使用内存库/临时库，在每个标注点主动中断或改变状态。

### 评论与回复

- [ ] `moment_comment_queue` 置 processing 后杀进程，重启能恢复。
- [ ] 评论已插入、queue 未置 done 时杀进程，恢复不重复。
- [ ] A 条目到期、B 条目未到期，处理 A 不得带走 B。
- [ ] LLM 返回前角色再次入睡，回复不得公开，醒后重试。

### 媒体与社交

- [ ] feed 图片 generating 时将作者删除/改系统角色，最终必须 discarded，不得 done。
- [ ] 图片已齐全但作者睡眠，醒后只发布，不再调用生图。
- [ ] 首评生成后、帖主回复前、续评前分别改变睡眠/开关，实际说话人均重新检查。
- [ ] 睡着角色输出文字、图片、文字+图片，三条路径一致拦截。

### 离线与日记

- [ ] 离线第 2 片失败、第 3 片成功，游标不能越过失败片。
- [ ] deferred 后保持进程在线，角色醒来可自动续，不要求重启。
- [ ] 日记延期后重启，确认稿与快照仍在；自动与手动重试不并发。
- [ ] 特殊日程 generating 后重启，窗口内恢复、窗口外过期。

### 外部服务与关闭

- [ ] ComfyUI 接受连接但不回 headers、只回 headers 不结束 body、WS 断开后 history 停住。
- [ ] 下载超过配置字节上限，任务失败而不是撑爆内存。
- [ ] 高优并发达到上限，低优等待可取消；退出先拒绝新任务。
- [ ] 本地超时但远端 prompt 状态不明时，重启不直接重复提交。

## 5. UI / UX 验收

### 数据准备

空库截图只能验空状态。正式验收至少准备：

- 3～6 个角色（含长名称、不同头像、睡眠/关闭开关/系统角色）；
- 私聊与群聊长消息、代码/链接、多图、失败与生成中状态；
- 2000+ 朋友圈数据用于分页性能；
- 媒体长标题、长正文、缺失图片；
- 角色长人设、多个服装、身份锚点；
- 至少两层嵌套弹窗与图片灯箱。

### 尺寸与主题

| 环境 | 页面 | 主题 | 检查点 |
|---|---|---|---|
| 1440×1000 | 聊天、群聊、朋友圈、设置、酒馆、媒体 | 暖色/暗夜 | 三栏、长文本、弹窗、列表、主按钮层级 |
| 1366×768 | 同上 | 两主题 | 矮屏导航与关闭键可达，无 flex 压线 |
| 1024×768 | 聊天、设置、角色详情 | 两主题 | 中间断点不挤压、不出现横向死区 |
| 390×844 | 全部核心页、移动建群、立绘页 | 两主题 | 底部安全区、输入框、抽屉、长内容滚动 |
| 320px | 设置、角色详情、世界观、弹窗 | 两主题 | 不横向溢出，控件可达 |
| 200% 缩放 | 设置、聊天、弹窗 | 两主题 | 内容不被裁切，焦点可见 |

### 键盘与动效

- [ ] 仅 Tab/Shift+Tab/方向键/Enter/Space/Esc 可进入所有一级页面。
- [ ] LinsheSelect 可搜索/非搜索均能用键盘选择；焦点样式清晰。
- [ ] 弹窗打开聚焦合理，Tab 不逃逸；嵌套 Esc 只关顶层；关闭后回触发器。
- [ ] Toast、灯箱、Tabs 可键盘操作；错误信息用适当 live region。
- [ ] 页面与窗口常规进/出均 300ms，关闭动画后再卸载。
- [ ] `prefers-reduced-motion` 下接近即时，不影响功能。
- [ ] 暖色/暗夜与系统原生控件配色一致；跨标签主题按设计同步。
- [ ] 浏览器 console 无未处理异常；网络面板无重复无限请求。

## 6. Android 与网络验收

### 设备矩阵

- [ ] Android 8（minSdk 26）一台。
- [ ] Android 10 一台。
- [ ] Android 13 或 14 一台；如支持更高 target/系统，再补当前主流版本。
- [ ] 至少一台有严格后台/电池策略的厂商 ROM。

### 功能与安全

- [ ] 配置合法地址；畸形 URL、不可达地址有明确错误，不静默保存为可用。
- [ ] 网页配对后原生 SSE 也授权；断网、切 Wi-Fi、服务重启后可恢复。
- [ ] 401 停止重连并提示重新配对；撤销单台设备后其他设备不受影响。
- [ ] 锁屏、App 退后台、重启手机、跨 90 秒读超时，通知与点击路由正确。
- [ ] 非批准 origin 的顶层页面/iframe 不能调用 AndroidBridge；外链交系统浏览器。
- [ ] 上传、图片保存、文件选择器在各版本正常；权限拒绝有解释。
- [ ] LAN HTTP 明确提示边界；录音/AudioWorklet 在不安全上下文的限制有文案或替代。
- [ ] 设备秘密不出现在日志、通知、普通网页存储与系统备份。
- [ ] release 签名升级路径验证；旧签名不再可用，迁移说明真实可执行。

## 7. 备份与兼容验收

| 场景 | 预期 |
|---|---|
| 无秘密导出 | 配置结构保留，秘密值全部空；归档扫描无已配置 Key |
| 含秘密导出 | 用户显式确认，manifest 只列秘密类别；不打印具体值 |
| 同版换机 | 角色、聊天、图片、音频完整；向量自动重建且可观察 |
| 旧版到新版 | schema version 逐版迁移；失败可回滚 |
| 新版回旧版 | 明确拒绝，不尝试“兼容”后破坏库 |
| 空 Chroma | 从 SQLite 全量重建 active 记忆，包括少于 20 条 |
| 残留错 profile Chroma | 不把旧 collection 当当前索引；按 fingerprint 重建 |
| provider 暂时离线 | 暂停重建并显示，不写 indexed，不用 null 维度探测 |
| 少图备份到多图环境 | 严格符合选择的快照或合并语义 |
| 恢复中强杀 | journal 可回滚/续做，不出现无提示混合世界 |
| 路径/链接/hash 恶意归档 | 拒绝，维护锁释放，原数据不变 |
| 中文/空格路径 | 打包、解压、启动、导入均正常 |

## 8. 生图与真实服务验收

### 生图冒烟

```bash
cd agent-core
DB_PATH=":memory:" ../runtime/nodejs/node.exe ../scripts/smoke-image.mjs
```

- 退出码 **0**：出图成功，可记录通过。
- 退出码 **2**：ComfyUI 未开/环境未满足，**不是通过**。
- 退出码 **1**：代码链路错误，阻断。
- 检查最终图片确实可解码、路径存在、身份/服装/LoRA/分辨率符合输入，不只看“返回成功”。

### 服务检查

- [ ] LLM 真实短文本、JSON、截断续写、流式、工具调用分别成功；测试成本受控。
- [ ] 向量服务启动、空库、索引、查询、停止；本地/远端 provider 各验。
- [ ] ComfyUI 单图、并队、取消、断连、重启；没有不明任务重复。
- [ ] TTS 模型存在时真合成并试听；GPU 与 ComfyUI 互斥，adapter 退出符合设计。
- [ ] NovelAI 若发布声明支持，至少验配置、生成、错误分类与密钥处理。

### 解压真启动

1. 解压到干净目录，至少包含中文与空格路径各一次。

6. 退出启动器，检查后端、向量、TTS worker 与相关进程是否按设计回收。
