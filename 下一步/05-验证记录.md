## 4. 对几个“看起来已完成”的准确解释

1. **后台状态校验**：已有统一睡眠与公开闸门，但不代表所有说话人/图片/落库点都调用。
2. **延期与无损重试**：近期修复保留快照与幂等基础，不等于 retry_at 有调度器兑现。
3. **媒体 discard 修复**：已覆盖部分入口，feed 的查询/认领/写回仍有竞态。
4. **备份校验**：有 hash/路径/DB 完整性，不代表秘密分类、资产替换和向量代际都正确。
5. **设备配对**：Web API 有保护，不代表 Android 原生 SSE 自动继承授权。
6. **63+56 测试**：保留用例能跑，不代表所有业务有覆盖；CI 当前也未运行它们。
7. **UI 统一组件**：基础完整，不代表所有弹窗、键盘、动画和裸控件都已收口。
8. **发布静态门禁**：能拦部分问题，不代表根 release、敏感历史、真机启动已通过。
