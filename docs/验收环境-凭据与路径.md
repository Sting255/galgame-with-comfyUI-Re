# 验收环境 · 凭据与路径

> **下次要跑真机验收，照这份来。** 下面这些值都在一台真实机器上跑通过，换成你自己的环境时逐项替换即可。
> **本文件不含任何密钥、内网地址或个人路径** —— Key 放 `agent-core/.env`（已 gitignore），别写回文档或提交历史。

## LLM

| 项 | 值 |
|---|---|
| Base URL | 指向你自己的 OpenAI 兼容网关，如 `http://127.0.0.1:7863/v1`（网关在内网另一台机器上就填那台的地址） |
| API Key | 见 `agent-core/.env` 的 `LLM_API_KEY`（**不入库**；`.env` 已在 .gitignore 里） |
| 模型 | `cn:deepseek-v4.1-flash` |
| 思考模式 | `disabled`（默认；个别中转 400 时改「不传」） |
| 写入位置 | `agent-core/.env` 的 `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` / `LLM_THINKING_MODE` |

连通性自检（Key 从 `.env` 读，别把明文写进文档或提交历史）：

```powershell
$key = (Select-String -Path agent-core\.env -Pattern '^LLM_API_KEY=').Line -replace '^LLM_API_KEY=',''
Invoke-RestMethod -Uri 'http://127.0.0.1:7863/v1/models' -Headers @{ Authorization = "Bearer $key" } |
  Select-Object -ExpandProperty data | Select-Object -First 5 id
```

## ComfyUI（生图）

| 项 | 值 |
|---|---|
| 安装目录 | 秋叶整合包（ComfyUI-aki-v3）的解压目录，例如 `<你的盘符>\ComfyUI-aki-v3` |
| 启动器 | 同目录 `绘世启动器.exe`（内含 `ComfyUI\`、`python\`、`git\`） |
| 无界面启动 | 同目录执行 `python\python.exe -s ComfyUI\main.py --port 8199`（2026-10-29 实测可用，约 10 秒起监听） |
| 监听端口 | **8199**（另有 8188 是其它实例，本项目不用） |
| 项目配置 | `agent-core/.env` 的 `COMFYUI_URL=http://127.0.0.1:8199` |

健康检查：

```powershell
Invoke-RestMethod -Uri 'http://127.0.0.1:8199/object_info' -TimeoutSec 20 | Select-Object -ExpandProperty CheckpointLoaderSimple
```

## 真机验收口径

1. 聊天：发一条消息，观察首字时间（目标本机 ≤ 1.5s）与是否出现 400。
2. 破限词：`logs/backend-*.log` 里 `预测 / 情绪判断 / AI判断行为 / 判断需要图片` **不应**出现 `注入破限提示词`。
3. 生图：聊天里触发图片，`[imageSkill] Workflow built` → `图片生成完成`；不应出现「已等 60s」告警。
4. 服装：角色详情 → 外观服装，四套（默认/私服/居家/睡衣）应 ≤1.5s 渲染；断网/接口 500 时应显示「加载失败 + 重试」而非永久「加载中…」。
5. 一键整套：点「一键生成整套系列」，四套一次生成并落库，面板自动刷新。

## 打包

```powershell
# 先把 .mimosa / logs / 完整 移出树，7z 打包，打完移回
& 'C:\Program Files\7-Zip\7z.exe' a -t7z -mx=9 -m0=lzma2 -md=512m -mfb=273 -mqs=on -ms=on -mmt=on "<输出>.7z" 'D:\邻舍改\*'
```

⚠️ **不要**用 `-xr'!logs'`：会误删 Python 的 `opentelemetry\proto\collector\logs`，解压后向量服务起不来。
输出目录：`D:\邻舍改\完整\`，校验写 `SHA256SUMS.txt` 与 `README-打包说明.md`。
