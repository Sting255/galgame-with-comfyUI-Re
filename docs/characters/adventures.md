# 奇遇：故事推进与恢复

入口是奇遇页。既有玩法包括角色故事、A/B 选项、自由行动、自定义事件动机、撤销上一步与往期记录；世界页已移除，不新增小镇玩法。

## 操作行为

- 同时最多推进两条奇遇；其余在本地等待，显示「正在排队」。等待时可返回重选，已发出的请求不能用取消排队按钮解锁。
- 每个排队请求都有完成结果：成功更新故事，失败显示提示；不会因排队丢掉错误。事件已删除或结算时撤掉对应等待项。
- 自由行动提交成功后清空输入，失败或取消排队时保留本卡片的文字。扰动世界线失败保留弹窗动机，成功后关闭。
- 撤销按事件 ID 更新，不使用请求前的列表位置；其他故事插入或移除不会让撤销覆盖错误卡片。
- 历史筛选没有结果时保留筛选条，可切回「全部」。加载失败显示重试，恢复后清掉旧错误。
- 后台刷新不自动清除未读；查看奇遇页时再标记已读。

排队属于当前前端会话，刷新浏览器不会保存尚未发送的选择。分支生成依赖现有模型与生图配置，界面重试不代表已完成真实模型联调。

## 数据边界

`processing` 是分支与到期/手动结算共同的数据库锁。结算先取得锁并重读当前事件，重复结算返回冲突；删除、取消也拒绝处理中事件。异常释放锁，允许稍后重试。遗留镇民事件使用相同保护，保持旧数据兼容。

取消操作在事务里写历史并删除活跃记录。角色结算把同步记忆写入和归档放在同一事务，归档失败会回滚；原有「记忆失败告警但允许故事归档」策略保持不变。历史保留原始 ID 和创建时间，结束时间仍由归档时间记录。

分支剩余时间在 15 分钟内才预览延长 5 分钟，随后以服务端结果为准。请求失败撤回尚未被服务端更新覆盖的本地预估。

## 代码入口

| --- | --- |
| `web-ui/src/views/EventsView.vue` | 角色选择、手动生成、历史筛选 |

| `web-ui/src/stores/events.js` | 本地排队、请求归属、列表与 SSE 同步 |

| `agent-core/src/services/eventProcessing.js` | 结算处理锁 |
| `agent-core/src/services/eventScheduler.js` | 到期调度 |
