## 三、本轮修掉的问题

1. **破限词无差别注入**（用户感知为「慢」）→ 短任务不注入 + 默认紧凑版。
2. **服装面板永久「加载中…」**（用户另一台机器踩到）→ 三态 + 重试 + 场景 key。
3. **批量生成入口被 `length > 1` 挡住** → 「一键生成整套系列」+ 兜底场景 + 生成后自动重拉。
4. **rerank `Query is too long`** → query 超 1000 字截断。
5. **居家服装没有鞋履口径**（PR24 缺口① 的一半）→ 居家=室内拖鞋/赤脚，禁户外鞋。
