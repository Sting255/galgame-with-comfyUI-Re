# 项目现状与接手入口

> 更新：2026-11-04。这份文件是接手第一站：项目是什么、怎么跑、现在什么状态、哪些是坑。
> 动手改代码前还要读 `AGENTS.md`（全仓契约）和 `docs/编程模式-DeepSeek.md`（干活顺序与验证阶梯）。

## 一、项目是什么

邻舍.EXE 是受 Galgame 启发的 AI 角色陪伴应用。角色有独立人格、情绪、记忆与生活节奏，可在私聊、群聊、朋友圈、信箱、日程、事件中持续互动，并按对话与场景调用 ComfyUI 出图。

本仓库是 [icecranberry/galgame-with-comfyUI](https://github.com/icecranberry/galgame-with-comfyUI) 的个人增强 fork，公开下载仓库为 `Sting255/galgame-with-comfyUI-Re`。

## 二、五块可执行部分

| 目录 | 职责 | 备注 |
| --- | --- | --- |
| `agent-core/` | Express + better-sqlite3 后端 | 40 个路由、150+ service、20 个后台调度器，核心 |
| `web-ui/` | Vue 3 + Pinia + Vite 前端 | 17 个页面、103 个组件，产物输出到 `agent-core/public` |
| `launcher/` | Python 启动器 | 托盘、日志、设置、服务启停与打包入口 |
| `tts-service/` | 本地 IndexTTS 2.0 | 与生图共用显卡，空闲自动退出 |
| `vector-service/` | Chroma 向量检索 | FastAPI，默认 8765 |

外围：`android-shell/`（WebView 壳）、`e2e/`（Playwright）、`scripts/`（开发、测试、打包脚本）、`runtime/`（内置 node/git/python，不进 git）。

## 三、怎么跑

```bash
# 开发（同时起后端、前端、向量服务，按 Ctrl+C 一起停）
node scripts/dev.mjs

# 全量回归（串行跑前后端，固定内存库与断网隔离）
runtime/nodejs/node.exe scripts/test-all.mjs

# 只改前端后重建产物
cd web-ui && ./node_modules/.bin/vite build
```

LLM 网关、ComfyUI 路径、端口与 Key 的位置固定在 `docs/验收环境-凭据与路径.md`，不要在会话里重新猜。真实数据库是 `agent-core/data/agent.db`，任何测试都不许落它；跑后端测试必须带 `DB_PATH=:memory:` 与 `--import ./test/setup.mjs`。

## 六、已知问题与债务（未修）

按风险排序，来自 2026-11-03 架构诊断与 2026-11-04 兼容性审查：

1. **后端零鉴权且默认监听全部网卡**。`/api/data/export` 可整库下载、`/api/data/import` 可整库覆盖，`/api/shutdown` 只认 `remoteAddress`。同网段设备或任何反代都可能触达。这是唯一有数据丢失后果的一项。
2. **`routes/chat.js` 单 handler 1884 行**，同时负责校验、上下文、记忆、情绪、亲密、催眠、生图、落库与 SSE 收尾，回归面无法界定。建议先抽「入参+上下文准备」与「产物 flush+落库」两段。
3. **小镇残留**：后端 `services/town/` 约 18475 行仍在，其中 2700+ 行不可达；前端保留 6 个组件与一整块永远 404 的 API。`chat.js` 仍依赖其中两个入口，删之前先确认。
4. **`db/index.js` 4113 行、189 张表、无 schema 版本机制**。每次启动跑全量幂等迁移，没有断点恢复。
5. **`web-ui/src/api/index.js` 2780 行、338 个导出**，另有 13 处直接 `fetch` 绕过 api 层。
6. **7 个模块依赖环**，其中 `db/settings.js` 头部注释与代码矛盾。
7. **20 个调度器手写在 `app.js`**，`shutdown` 只停 2 个，测试靠 `--test-force-exit` 兜底。
8. **无 CI**，全量回归只能手动跑。

**不是 bug 的设计边界**：程序时间（`timeControl.js` 的 `REAL_TIME_ONLY`）与后台排期有意分离——信箱、朋友圈排期、事件排期仍按真实时间走，推进游戏一天不会让后台玩法立刻跑完一天。要改需先统一时间语义，别当缺陷修。小镇残留组件仍被聊天/事件/朋友圈引用，但朋友圈镇民生成有 `config.features.town === true` 门控，不会自行复活。

## 七、交接约定

- 改前端走 Linshe 组件，皮肤只改组件文件；页面切换与弹窗 0.3s 过渡。
- 涉及生图的角色人格一律走 `characterPersona.js`；生效外观只走 `outfitService.getActiveOutfits`。
- 要求模型出 JSON 时，prompt 里必须给完整示例并同步解析代码。
- 临时脚本放 `%TEMP%`，跑完删；要反复跑的回归改写成正式测试。
- 用户可见行为变化要同步 `scripts/usage-guide.mjs`（生成 `使用说明.txt` 的唯一正源）。
