# 编程模式 · 仓库执行约定

本文件管执行流程；[AGENTS.md](../AGENTS.md) 管全仓契约；[文档导航](README.md) 指向功能设计。冲突时以 AGENTS.md 和用户当前授权为准。

## 开工

1. 读 [项目现状](项目现状.md)，查看最近 20 条提交与 Git 状态，保留他人未提交修改。
2. 按 [文档导航](README.md) 找对应功能口径。UI 修改读 [设计系统](design-system.md)；验收读 [本机环境](验收环境-凭据与路径.md)，不猜端口与凭据。
3. 读 [测试说明](testing.md)，用 rg --files 定位源码。以代码、日志和实际行为下结论，不把文档当事实。
4. 默认只检查程序：源码、配置契约、构建产物和合成测试数据，不读取玩家旧库或素材。确认本轮程序基线；同一会话且业务代码未变化时可复用刚完成的全量结果。
5. 动手前说明需求、改动范围和验证方式。有行为歧义才问，不重复请求用户已给的授权。

## 实施

- 一次改一条链，先定向测试，再全量回归。大文件沿职责边界抽取，保持外部接口和上游合并兼容。
- UI、LLM JSON 示例、角色外观组装、临时测试归属按 AGENTS.md 执行，不在这里复制规则。
- 文档过时就纠正文档，不为让测试变绿而抹掉仍有效的行为约束。
- 连续三轮仍无法定位就说明缺失的复现信息，不反复猜改。

## 数据与环境纪律

- 工作目录 D:\邻舍改。不要进入旧 release 快照、源码、运行时和依赖目录修改业务；允许复用 bundled Node/Git。
- agent-core/data/ 是玩家数据，排除出日常程序检查、搜索与验收。后端单测用内存库；导入/恢复等磁盘验证用系统临时目录的合成库。旧存档、缺图与历史素材不是程序待修项；只有用户另行要求数据维护时才检查。
- Node 用 runtime/nodejs/node.exe；Git 用 runtime/git/cmd/git.exe。不要用 ABI 不匹配的 PATH Node 加载 better-sqlite3。
- 后端测试必须加载 agent-core/test/setup.mjs，默认断网。真实 LLM、ComfyUI 联调需已有用户授权。
- 启动服务先查目标端口，结束时只停自己启动的进程。启动异常、非零退出码、cancelled 均算失败。
- PowerShell 中文多行用 here-string；不用 Get-Content | Set-Content 改 UTF-8 源码。rg 路径不写 shell 通配符，使用目录加 -g。
- 临时脚本和日志放系统临时目录，清理自己生成的文件。真实数据、素材和旧分发包不按“看着没用”删除。
- 后端无时区时间为 UTC；前端使用统一解析入口。GET /forgotten 不带 query 与 ?status= 含义不同。

## 验证阶梯

| 层 | 验证内容 |
| --- | --- |
| L1 | 正式 bug 回归，包含失败路径与边界 |
| L2/L3 | 根目录运行 runtime/nodejs/node.exe scripts/test-all.mjs，前后端串行，不并发两套全量 |
| L4 | 修改 web-ui/src 后在 web-ui 运行 ../runtime/nodejs/node.exe build.mjs；assets 已被 Git 忽略，index.html 仍需核对 |
| L5 | 临时库 + 真实 HTTP + 本机桩，验证跨模块接线 |
| L6 | 有浏览器工具就实际点击；否则明确没验并给操作清单。旧代理没有浏览器能力不是永久限制 |

报告包含 tests / pass / fail / skipped / cancelled，解释失败与跳过。具体命令只维护在 [测试说明](testing.md)。

## 收工

- 检查 Git 差异、临时残留和测试隔离结果。日常收工不扫描旧数据库、不做玩家图片体检。scripts/dead-image-check.mjs 仅用于用户另行指定的数据维护，不作为程序质量门禁。
- 用户行为变化同步功能文档与 scripts/usage-guide.mjs，后者是使用说明的唯一正源。
- 当前状态和未解决问题只写 [项目现状](项目现状.md)。不要再新增逐轮调查报告或复制接手手册。
- 通用教训写 .learnings/；专题内旧验收记录可保留为依据，但不能充当本轮结果。
- 说明完成项、验证结果、未完成边界与下一步。未授权不提交 Git、不打包、不消耗真实模型额度。
