## 已知边界（不用当 bug 报）

1. **认不出调用链的 LLM 调用照常注入**。投递范围是按调用方的中文标签前缀识别的（`私聊…`→chat、`奇遇…`→event …），认不出来就返回「照常注入」。所以个别内部工具调用可能"不入册但也没被过滤" —— 这是刻意的（漏映射的后果是少一条过滤，不是破限词失效）。
2. **某模块把上游破限词拼到 system2 之后**时，本地这份会跟着插到它后面（不纠正上游的位置）。那是各调用链自己的事。
3. **正文里的 `{{xxx}}`**：只有 `{{cwd}}` / `{{model}}` / `{{provider}}` 会被当合法插值点，其它会被拆成 `{ {xxx}}`（防止模板引擎把整段吃掉）。这是为 dsh 移植过来的正文准备的保险。
4. **单套正文超过 64 KB 会被截断**，全部规则集超过 256 KB 会保存失败 —— 页面上会给出提示。
5. **规则集不影响 JSON 输出格式**。它只管"愿不愿意写"，不管"怎么排版"；手动点题、日程强 JSON 这些契约照旧。
